# Quantum Computing

An animated introduction to quantum computing, created using Python and Manim, for COM 217 (Science Writing & Presentation). 

## Overview

This project is a short educational animation that introduces quantum computing concepts in a simple, approachable way as outlined by the requirements of a Communications project with four other co-collaborators. 
The animation uses visual storytelling to make abstract technical concepts easier to understand.

## My Contribution

I designed and coded the entire animation using Manim, translating the project's explanations into visual scenes and animations.
